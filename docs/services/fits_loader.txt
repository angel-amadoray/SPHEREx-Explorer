# SPHEREx Level 2 FITS Loading and Processing Module

## What It Is About  
This module handles opening, validating, and processing the Level 2 FITS files generated by SPHEREx. These FITS files contain spectral image data in a specialized multi-extension format designed to store scientific observations with spatial and spectral calibrations.

---

## Key Components and Concepts

### FITS File Structure  
Each SPHEREx Level 2 spectral image is a multi-extension FITS (MEF) file including:

- `PRIMARY`: Main header and metadata.  
- `IMAGE`: The calibrated spectral image data.  
- `FLAGS`: Pixel quality and reliability flags.  
- `VARIANCE`: Noise estimates for each pixel.  
- `ZODI`: Background zodiacal light model for subtraction.  
- `PSF`: Point spread function data.  
- `WCS-WAVE`: Spectral wavelength coordinate table.

Spectral information is stored not as a cube axis but through a wavelength lookup table referenced by the `WCS-WAVE` extension.

---

## Core Functions

### Safe FITS File Access  
Opens FITS files with memory mapping for efficiency, validates presence of required extensions, and prevents file path injection via strict ID validation.

### World Coordinate System (WCS)  
Extracts spatial WCS (RA/Dec) from the header, preserving distortion models. Separately extracts spectral WCS, removing spatial distortion keys to correctly interpret wavelength mapping.

### Spectral Wavelength Mapping  
Builds a 2D array mapping each pixel to its spectral wavelength in micrometers by evaluating the spectral WCS. Supports downsampling and interpolation to balance accuracy and performance.

### Clean Image Extraction  
Produces a clean scientific image by subtracting zodiacal light background and masking out pixels flagged as unreliable based on known bad-bit masks.

### Pixel-Wavelength Extraction and Photometry  
Retrieves wavelength and bandwidth at a pixel and performs aperture photometry to estimate flux, error, and signal-to-noise ratio.

### Filename Parsing and File Discovery  
Extracts metadata from standardized SPHEREx FITS filenames (sector, epoch, detector, obs_id, etc.) and searches local disk directories for matching files, with optional filters.

---

## Utilities and Conversion

- Conversion functions between pixel coordinates and celestial coordinates using the WCS.  
- Serialization helper to convert FITS headers into JSON-compatible dictionaries for diagnostics or frontend use.  
- Variance data extraction for noise analysis.

---

## Why It Matters

This module forms the foundation for reliable, efficient access and interpretation of SPHEREx Level 2 data, enabling higher-level analysis, visualization, and scientific discovery.
