# OCI FITS Upload Script

## What It Is About  
This script uploads local FITS image files to a remote OCI (Oracle Cloud Infrastructure) bucket, which is compatible with S3 protocol. It respects the directory organization by sector and epoch, allowing selective uploads or listing bucket contents.

---

## How It Works

### 1. OCI Client Setup  
Reads OCI credentials and configuration from environment settings, and creates a secure client for S3-compatible interactions. Exits with an error if required credentials are missing.

```python
def get_client():
    if not (settings.oci_endpoint and settings.oci_access_key
            and settings.oci_secret_key and settings.oci_bucket):
        print("? Missing OCI_* variables in your .env")
        sys.exit(1)
    return boto3.client(
        "s3",
        endpoint_url=settings.oci_endpoint,
        aws_access_key_id=settings.oci_access_key,
        aws_secret_access_key=settings.oci_secret_key,
        region_name=settings.oci_region or None,
        config=Config(
            signature_version="s3v4",
            request_checksum_calculation="when_required",
            response_checksum_validation="when_required",
        ),
    )
```

### 2. Listing Bucket Contents  
Lists all files currently in the configured OCI bucket under the defined prefix, reporting file sizes and total count. Does not perform any uploads.

```python
def list_remote(client):
    paginator = client.get_paginator("list_objects_v2")
    prefix = settings.oci_prefix + "/"
    total = 0
    for page in paginator.paginate(Bucket=settings.oci_bucket, Prefix=prefix):
        for obj in page.get("Contents", []):
            print(f"  {obj['Size']/1e6:8.1f} MB  {obj['Key']}")
            total += 1
    print(f"\nTotal: {total} files")
```

### 3. Uploading Files  
Recursively iterates over the local data directory structured in sector/epoch folders. Filters uploads by sector and/or epoch if specified. Each FITS file is uploaded preserving the directory structure as object keys.

```python
def upload_all(client, sector_filter=None, epoch_filter=None):
    root = Path(settings.data_dir)
    if not root.is_dir():
        print(f"? Directory {root} does not exist")
        sys.exit(1)

    uploaded = 0
    for sector_dir in sorted(root.iterdir()):
        if not sector_dir.is_dir():
            continue
        if sector_filter and sector_dir.name != sector_filter:
            continue
        for epoch_dir in sorted(sector_dir.iterdir()):
            if not epoch_dir.is_dir():
                continue
            if epoch_filter and epoch_dir.name != epoch_filter:
                continue
            for fits_file in sorted(epoch_dir.glob("*.fits")):
                key = f"{settings.oci_prefix}/{sector_dir.name}/{epoch_dir.name}/{fits_file.name}"
                size_mb = fits_file.stat().st_size / 1e6
                print(f"??  {size_mb:7.1f} MB  {key}")
                client.upload_file(str(fits_file), settings.oci_bucket, key)
                uploaded += 1
    print(f"\n? Uploaded {uploaded} files")
```

### 4. Command-Line Interface  
Uses command line arguments to specify optional filters (sector, epoch) or to list bucket contents instead of uploading.

```python
def main():
    p = argparse.ArgumentParser()
    p.add_argument("--list", action="store_true", help="List bucket files (no upload)")
    p.add_argument("--sector", help="Upload only this sector")
    p.add_argument("--epoch", help="Upload only this epoch")
    args = p.parse_args()

    client = get_client()
    if args.list:
        list_remote(client)
    else:
        upload_all(client, args.sector, args.epoch)
```

## Benefits  
- Enables selective and organized bulk upload of astronomical FITS files to cloud storage.  
- Preserves local directory structure in the remote bucket for easy retrieval.  
- Provides safeguard with bucket listing option to verify remote contents before upload.  
- Uses efficient pagination and boto3 features for scalable file management.

## Use Cases  
Ideal for scientific computing environments needing to sync large local datasets to OCI cloud for remote processing, backup, or sharing.
