# SPHEREx Local Pixel Spectral Analyzer (Level 2)

## About This Analysis  
Because each SPHEREx exposure captures only one wavelength per pixel and a point source covers only a few rows (wavelengths), a single detector provides a very narrow spectral range (~1-3 nm). This limits detailed measurements like temperature or composition, so instead the analysis estimates a **statistical color classification** based on the ratio of long to short wavelength flux.

### Color Classification  
- **STAR_LIKE**: color ratio < 0.85 (more flux at short wavelengths → bluer)  
- **ROCKY_LIKE**: color ratio > 1.15 (more flux at long wavelengths → redder)  
- **UNKNOWN**: spectral slope too flat, noisy, or insufficient wavelength range

---

## Step-by-Step Pipeline

1. **Pixel Cutout Extraction**  
   Extracts a 60×60 pixel neighborhood around the clicked pixel, recording the clean image, wavelength map, variance, and edge proximity.

2. **Aperture Photometry**  
   Measures flux within a 5-pixel radius circular aperture around the center and subtracts background estimated from an annulus between 8-15 pixels radius. Also calculates signal-to-noise ratio (SNR).

3. **Micro Spectral Profile**  
   Walks row by row through the cutout, measuring mean flux in a sliding aperture for all rows with sufficient valid data, building a micro-spectrum.

4. **Color Ratio Computation**  
   Uses median flux of the lowest and highest wavelength rows to compute the ratio F_long / F_short, propagating errors if variance data is available.

5. **Classification with Significance Threshold**  
   Classifies candidate only if the ratio deviation from 1 is statistically significant (>1.5× ratio error) and the wavelength range is sufficient.

6. **Visual Hints Generation**  
   Suggests colors, roughness, metalness, emission intensity, and 3D model types for visualization based on classification confidence and color ratio.

---

## Key Functions

- `_extract_cutout`: Handles safe image crop with edge checks.  
- `_aperture_photometry`: Performs flux and SNR estimation.  
- `_spectral_cutout`: Samples flux and wavelength row-wise to build spectrum.  
- `_compute_color_ratio`: Calculates color ratio from spectral edges.  
- `_classify_color`: Applies thresholds and assigns candidate class.  
- `_visual_hints`: Provides parameters for visualization styles.  
- `analyze_pixel`: Orchestrates the full pipeline, returning structured result including candidate class, confidence, flux, SNR, spectral points, and visual hints.

---

## Importance

This analysis, despite physical limitations, provides a rapid, statistical way to characterize and classify sources as star-like or rocky-like candidates directly from SPHEREx single-pixel spectral data. It guides deeper analysis and visualization effectively.
