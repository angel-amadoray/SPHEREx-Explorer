# Analytics API Module

## What It Is About  
This module implements an API to analyze astronomical image data. It offers endpoints for computing differences between images, identifying known celestial objects within a field of view, profiling spectra of pixels, and more. The system efficiently handles large datasets and uses caching to improve performance.

---

## How It Works

### 1. Image Difference Calculation  
This endpoint computes the difference between two image epochs for a specified sky sector and detector. Various parameters control background noise removal, normalization, masking, and thresholding. It leverages cached results to avoid recomputation.

- Validates requested sector and epochs.
- Checks cache with stable keys based on parameters.
- Loads image data or raises errors if missing or invalid.
- Computes the difference with precise options.
- Stores and returns the processed image and metadata.

- Parses results, optionally computing pixel coordinates.

### 4. Spectrum Analysis of Pixels  
This endpoint analyzes the spectral profile of a specific pixel in an image, returning wavelength and flux data.

- Validates sector and epoch.
- Loads image and ensures pixel coordinates are valid.
- Calls spectral analyzer service on that pixel.
- Returns detailed spectral data.

```python
@router.get("/spectrum", response_model=SpectrumResponse)
def spectrum(
    # parameters omitted
):
    hotspot = request.app.state.hotspots.get(sector_id)
    if hotspot is None:
        raise HTTPException(404, f"Sector '{sector_id}' not found")

    hdul = fl.load_local_fits(...)
    ny, nx = hdul["IMAGE"].data.shape
    if pixel_x >= nx or pixel_y >= ny:
        raise HTTPException(400, "Pixel out of bounds")

    result = sa.analyze_pixel(hdul, pixel_x, pixel_y)
    wavelengths = result.pop("spectrum_wavelengths", [])
    fluxes = result.pop("spectrum_fluxes", [])
    profile = SpherexProfile(**result)

    return SpectrumResponse(
        sector_id=sector_id,
        epoch=epoch,
        detector=detector,
        pixel_x=pixel_x,
        pixel_y=pixel_y,
        wavelengths_um=wavelengths,
        flux_per_row=fluxes,
        profile=profile,
    )
```
